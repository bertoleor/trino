# Checklist de aprobación — trino.

## Contenido
- [ ] La pieza tiene una sola idea principal.
- [ ] El producto, beneficio y acción están identificados.
- [ ] El tono es directo, cómplice, expresivo y útil.
- [ ] Los datos de producto y condiciones promocionales fueron validados.

## Identidad
- [ ] Se usaron archivos oficiales del logo.
- [ ] El logo conserva su área de seguridad y tamaño mínimo.
- [ ] La composición usa un color pop protagonista y, como máximo, un acento.
- [ ] Los patrones no compiten con información funcional.

## Accesibilidad
- [ ] El texto usa una combinación aprobada en la matriz AA.
- [ ] No hay texto directamente sobre patrones o fotografía sin protección.
- [ ] Los controles tienen etiqueta y foco visible.
- [ ] La pieza no comunica información solo mediante color.
- [ ] Las animaciones respetan prefers-reduced-motion.

## Producción
- [ ] Las imágenes tienen resolución suficiente y permiso de uso.
- [ ] Packaging: troquel, sangrado, tintas y textos legales fueron validados.
- [ ] Se revisaron mobile, desktop e impresión según corresponda.
- [ ] El archivo final sigue la convención canal_campaña_formato_fecha_v##.
