# trino. Brand Starter Kit — v1.0

## Estructura
- Logos: variantes maestras en SVG.
- Sistema: tokens semánticos, patrones e iconos.
- Social: seis templates SVG editables.
- Digital: home y ficha de producto.
- Packaging: base conceptual para adaptar al troquel real.
- Guías: checklist y este README.

## Uso rápido
1. Empezá con Cream como superficie dominante.
2. Elegí un color pop protagonista y uno de acento.
3. Usá Ink para texto sobre fondos claros/pop y Cream sobre Ink/Cobalt.
4. Nunca pongas texto directamente sobre patrones.
5. Validá cada pieza con trino-checklist-aprobacion.md.

## Tipografías
- Display: Fredoka Semibold/Bold.
- Texto y UI: DM Sans Regular/Medium/Bold.

## Importante
Los SVG de packaging son guías conceptuales. Requieren adaptación técnica, pruebas de color y revisión legal antes de producción.
