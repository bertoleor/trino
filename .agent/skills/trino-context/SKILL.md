# trino. Product Context

## Identity & Brand

- Storefront brand is **`trino.`** — Neo-Bauhaus _"forma sigue a función"_. Every visual element
  must carry functional purpose. No decorative-only UI.
- Brand values: terracota/verde/mostaza/celeste palette, pills `border-radius:50px`, lowercase
  `text-transform`, geometric Bauhaus shapes for hero/category blocks.
- Triple taxonomy per `marca.md §3`: `type` (tarot, velas...), `tradition` (wicca, budismo...),
  `intention` (amor, protección...). Filters MUST be combinable (intersect), never separate menus.

## Stack (verified from package.json / configs)

- **Next.js 16.3.4** (App Router), React 19.2.8. `next.config.ts` wraps with `withNextIntl`
  (`./src/i18n/request.ts`).
- **TypeScript strict** — `strict:true`, **`noUncheckedIndexedAccess:true`**. Index access returns
  `T | undefined`; handle it. Aliases: `@/* → ./src/*`.
- **decimal.js** for money. **zod ^4** for validation, incl. env.
- **Supabase** (`@supabase/ssr` + `@supabase/supabase-js`) with RLS. **Upstash Redis + ratelimit**.
- **next-intl ^4** — locales `es-AR` (default), `en`, `fr`, `pt-BR` (`messages/<locale>/*.json`).
- **Vitest ^4** (unit/integration in `tests/`), **Playwright** (e2e in `tests/e2e`), **husky 9** +
  **lint-staged** for pre-commit.
- **Stamp `eslint-ignore` on `.next`, `out`, `coverage`, `src/types/database.types.ts`,
  `next-env.d.ts`**.
- Package manager: **pnpm** (`pnpm-workspace.yaml`). Locked `packageManager: pnpm@11.25.0`.

## Cost-Zero Principle (binding)

Every tool/plugin must be free (no paid tier, no heavy extra dep). When a heavy plugin is rejected,
record the native-rule alternative in `design.md`. See `trino-eslint-gates`.

## Style Baseline (verified .prettierrc.json)

`printWidth 100, singleQuote, semi, trailingComma es5, endOfLine lf, arrowParens always, tabWidth 2`.
Markdown: `proseWrap preserve`. Format-on-save MUST produce exactly what `prettier --check` expects.

## Routing & Locale (verified from src/app)

- All public routes live under `src/app/[locale]/` (account, admin, auth, login, producto, signup,
  etc.).
- Server-side API under `src/app/api/`; low-level `src/proxy.ts` and `src/instrumentation.ts` hold
  edge/observability logic.
- DB types regenerated by `pnpm gen:types` → `src/types/database.types.ts`. Never hand-edit; it is
  gitignored from lint.

## Non-Negotiables (cross-cutting)

- **No emojis in code** (CQ-08). `no-restricted-syntax` bans the emoji literal range.
- **No `console.*`** — errors go through `src/lib/logger.ts`. Zero-build-warnings gate.
- **Money only as integer centavos, ARS only.** See `trino-money-arithmetic`.
- **Secrets only via `src/config/env.ts`** Zod, fail-closed at boot. Never `process.env` inline,
  never `as unknown as`.
- **RBAC via `has_role()` `SECURITY DEFINER`** — never `IN SELECT`. See `trino-admin-backoffice`.

## Deviation Rule

If a spec requirement conflicts with what you "know", the `openspec/specs/<domain>/spec.md` is
authoritative. Note any deviation in code comments with the CQ/ECOM/etc. trace id.
